FIX Orchestra metadata
======================

xml/standard/FIXLatest-metadata.xml is a mechanical projection, made by
tools/orchestra_projection.py, of OrchestraFIXLatest.xml from the FIX Trading
Community's orchestrations repository:

  Repository: https://github.com/FIXTradingCommunity/orchestrations
  Commit:     cd24169a2abd8daba7c360987c7a46ca11873a12
  Path:       FIX Standard/OrchestraFIXLatest.xml
  Retrieved:  2026-09-16
  Source SHA-256: 1bf82a22423d6504fbb77c4c8c522a4efefb32aec19b630c138860ccddf8228d
  Output SHA-256: see xml/README.md and xml/standard/SHA256SUMS

The projection retains only: field id, name, base type, added, addedEP,
deprecated, ownCodeSet and the first non-empty SYNOPSIS; per code its value,
name, added, addedEP, deprecated and the first non-empty SYNOPSIS; and message
type, name, category and the first non-empty SYNOPSIS. Nothing else from the
source file is reproduced.
